Il progetto mira a implementare il network slicing in una rete virtualizzata mediante \textit{Mininet}, sfruttando la libreria Python e l'emulatore di controller \textit{Ryu}. L'implementazione è organizzata nelle seguenti sezioni:
\begin{enumerate}
    \item \textbf{Topology-slicing}: Restrizione delle rotte di comunicazione tra specifici host;
    \item \textbf{Service-slicing}: Differenziazione del trattamento di determinati tipi di traffico.
\end{enumerate}

\noindent
Per ogni sezione sono previsti test di validazione dei risultati ottenuti.
